## 2026-11-08 - Prevent Pillow Decompression Bombs\n**Vulnerability:** The application parses raw and TIFF images without an explicit limit on image dimensions, making it susceptible to decompression bombs (DoS through memory exhaustion).\n**Learning:** In desktop image processing tools, relying on Pillow's default limits or leaving them unconfigured can lead to application crashes when processing untrusted inputs.\n**Prevention:** Set `Image.MAX_IMAGE_PIXELS` to a reasonable upper bound (e.g., 100_000_000) to protect against resource exhaustion while supporting high-resolution scans.
